# Proj0058: Remove legacy project nodes
Project files that were created with the MSBuild ([non-SDK](https://learn.microsoft.com/dotnet/core/project-sdk/overview)
project system contain nodes that have no meaning for the .NET SDK. When
converted (as suggested by [Proj0002](Proj0002.md) some of those nodes are left
behind. These relics only add noise, and should be removed.

## Non-compliant
```xml
<Project Sdk="Microsoft.NET.Sdk">

  <PropertyGroup>
    <ProjectGuid>{ECC1C67A-4BD7-400F-92C5-39395F05B586}</ProjectGuid>
    <AppDesignerFolder>Properties</AppDesignerFolder>
    <AssemblyName>Legacy</AssemblyName>
    <TargetFrameworkVersion>v4.8</TargetFrameworkVersion>
  </PropertyGroup>

</Project>
```

## Compliant
```xml
<Project Sdk="Microsoft.NET.Sdk">

  <PropertyGroup>
    <TargetFramework>net10.0</TargetFramework>
  </PropertyGroup>

</Project>
```
