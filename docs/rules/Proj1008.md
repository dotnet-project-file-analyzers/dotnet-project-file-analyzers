# Proj1008: Remove configuration for not-configurable rule
Some diagnostic rules are not configurable. Their severity cannot be modified
or suppressed. Code that attempts to configure these rules should therefore be
removed.

## Non-compliant
Non-compliant code should simply be removed:

### MSBuild files
```xml
<Project Sdk="Microsoft.NET.Sdk">

  <PropertyGroup>
    <TargetFramework>net10.0</TargetFramework>
    <NoWarn>CS0016</NoWarn>
  </PropertyGroup>

</Project>
```

### .globalconfig and .editorconfig files
``` ini
dotnet_diagnostic.CS0016.severity = none
```

### C# Source
```csharp
#pragma warning disable CS0016 // Non-compliant

[SuppressMessage("Category", "CS1680")] // Non-compliant
public class SomeClass
{
}
```
