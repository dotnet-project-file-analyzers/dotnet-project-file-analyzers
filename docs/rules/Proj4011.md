# Proj4011: Define INI keys once
An [INI file](https://en.wikipedia.org/wiki/INI_file) is a plain text file with
a structure and syntax comprising key–value pairs organized in sections.

Within a section of an INI file, defining the same key multiple times is
redundant and can lead to confusion, as subsequent definitions will override
previous ones. Each key should be defined at most once per section. Different
sections can define the same key since they apply to different scopes.

## Non-compliant
``` ini
root = true

[*.cs]
indent_style = tab
indent_size = 4
indent_style = space
```

## Compliant
``` ini
root = true

[*.cs]
indent_style = space
indent_size = 4
```
