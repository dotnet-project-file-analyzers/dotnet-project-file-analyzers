# Proj4012: Comma separated values should not end with a comma
Comma separated values in `.ini` files should not end with a comma. A trailing
comma is redundant and typically the result of a typo.

## Non-compliant
``` ini
dotnet_code_quality.CA1822.api_surface = public,private,
```

## Compliant
``` ini
dotnet_code_quality.CA1822.api_surface = public,private
```
