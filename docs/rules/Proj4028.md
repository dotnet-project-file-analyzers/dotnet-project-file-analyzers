# Proj4028: Use explicit diagnostic severity level
Using `default` in global configurations creates ambiguity because it relies on
hidden fallbacks. Setting an explicit value ensures clear, self-documenting
intent.

## Non-compliant
``` ini
is_global = true
        
dotnet_diagnostic.IDE0002.severity = default
```

## Compliant
``` ini
is_global = true
        
dotnet_diagnostic.IDE0002.severity = warning
```
