# Proj4029: Use known diagnostic IDs
This rule ensures that configuration entries target valid diagnostic IDs.
As we can only certain about our own rule, only diagnostic IDs with the
`Proj` prefix are checked.

## Non-compliant
``` ini
is_global = true
        
dotnet_diagnostic.Proj001.severity = warning
```

## Compliant
``` ini
is_global = true
        
dotnet_diagnostic.Proj1001.severity = warning
```
