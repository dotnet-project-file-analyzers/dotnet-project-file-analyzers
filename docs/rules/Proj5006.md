# Proj5006: Included files should exist
TODO

## Non-Compliant
``` xml
<Solution>
  <Folder Name="/Solution Items/">
    <File Path="non-existing.file" />
    <File Path="existing.file" />
  </Folder>
  <Project Path="src/SomeProject.csproj" />
</Solution>
```

## Compliant
``` xml
<Folder Name="/Solution Items/">
    <File Path="existing.file" />
  </Folder>
  <Project Path="src/SomeProject.csproj" />
```
