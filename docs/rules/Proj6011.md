# Proj6011: Specify SDK version
A [`global.json`](https://learn.microsoft.com/dotnet/core/tools/global-json) file
should specify a valid .NET SDK version. By doing so, the .NET CLI can pin the
SDK to a predictable release.

## Non-compliant
Any `global.json` withoout the `sdk.version` path being set with a
valid [semantic version](https://semver.org/).

## Compliant
`global.json`
```json
{
  "sdk": {
    "version": "10.0.400",
  }
}
```
